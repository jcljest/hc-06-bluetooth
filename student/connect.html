Sensor Connect

Talk to your Arduino + HC-06 over Bluetooth. Use Google Chrome.

Not connected
Sensor not in the list?
  • Pair it first: System Settings → Bluetooth → your sensor's name → Connect (PIN 1234).
  • Renamed it? Click ⓘ next to the old name → Forget This Device, then pair again.
  • Only one computer or phone can connect at a time. Disconnect anything else.
  • Chrome needs Bluetooth access: System Settings → Privacy & Security → Bluetooth → Google Chrome on.
